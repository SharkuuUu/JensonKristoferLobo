JENSON KRISTOFER LOBO - CYBERSECURITY PORTFOLIO

Files:
- index.html
- style.css
- script.js

Before publishing:
1. Open index.html.
2. Replace YOUR_EMAIL@example.com with your email.
3. Replace YOUR_USERNAME with your GitHub and LinkedIn usernames.
4. Update project descriptions and add your screenshots/links.

GitHub Pages:
1. Create a repository named YOUR_USERNAME.github.io.
2. Upload all three website files.
3. Go to Settings > Pages.
4. Select Deploy from a branch.
5. Select main and / (root), then Save.
6. Your website will appear at https://YOUR_USERNAME.github.io
